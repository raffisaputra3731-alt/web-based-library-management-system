# Web-Based Library Management System

A database-driven web application developed as part of the Database course at Universitas Negeri Jakarta (September–December 2025).

## Overview
This project aims to streamline library operations through an integrated web-based system, providing efficient management of book inventories, library members, and borrowing transactions.

## Features
- Administrator Dashboard
- Book Inventory Management
- Library Member Management
- Book Borrowing and Return Management
- Transaction History Tracking
- Book Availability Monitoring
- Admin Authentication
- Library Statistics Dashboard

## Technologies
- HTML, CSS, JavaScript
- PHP
- Python
- MySQL
- XAMPP
- phpMyAdmin

## Database
MySQL is used to store and manage library data, including book records, member information, and borrowing transactions.
